# USP-010: 24/7 AI Financial Advisor (Premium Tier)

## Status

- **Type**: Unique Selling Point
- **Priority**: Premium (Must Have for Premium Tier)
- **Status**: Draft

## Description

A context-aware LLM grounded in the user's real-time ledger data, providing personalized answers to complex cross-border financial questions.

## Value Proposition

- **Money Saver**: Offers "Private Wealth Management" logic at a fraction of the cost of a human advisor.
- **Convenience**: 24/7 availability for urgent financial decisions.
- **Expat Focused**: Specialized in cross-border volatility, tax residency implications, and international rebalancing.

## Example Use Case

"If I move from Japan to Mexico next month, how should I rebalance my savings to account for the current Yen-Peso volatility?"

## Technical Foundations

- Grounded in **real-time ledger data** (Accounts, Transactions, FX).
- Leverages the **FX Service** for historical and current rate analysis.
- Respects **Tenant Isolation** and **Zero-Knowledge** principles (see AI-004).

## Success Metric

- **Retention**: Increase in high-tier subscription renewals.
- **Engagement**: > 3 queries per premium user per month.
