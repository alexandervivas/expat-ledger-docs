# Requirement FR-016: Dark Mode & Theming

## Status

- **Type**: Functional Requirement
- **Priority**: Could Have
- **Iteration**: 5
- **Status**: Draft

## Description

Allow users to toggle between Light and Dark visual themes.

## User Story

As a user, I want to switch to dark mode at night so that the dashboard is easier on my eyes.

## Acceptance Criteria

- System follows OS preference by default.
- Persistence of theme selection across login sessions.

## Functional Requirements

1. **Theme Toggle**: Provide a UI element to switch between Light, Dark, and System (Auto) themes.
2. **Persistence**: Store the user's theme preference in their profile.
3. **OS Synchronization**: Automatically adapt the theme if "System" is selected, based on the operating system's settings.
